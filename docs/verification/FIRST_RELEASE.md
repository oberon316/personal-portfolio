## 第 6 节实际执行

1. 按现有 schema 整理文字，使用 src/api 生成文字导入包。在独立本机 origin 127.0.0.1:4177 的后台导入，避免覆盖日常开发来源上可能已有的草稿。
2. 进入个人资料表单保存，并通过文件选择器上传原头像与公开 PDF，实际写入 localStorage / IndexedDB。
3. 刷新后台，确认资料和文件仍存在；在 /preview 与项目详情核对文案。
4. 使用设置页面导出完整备份 ZIP，仓库外另存“许圣哲网站_完整备份.zip”，261862 字节。备份包含所有文字和两个文件。
5. 使用设置页面导出静态发布 ZIP，仓库外另存“许圣哲网站_静态发布包.zip”，262112 字节。校验 ZIP CRC、结构和二进制内容后解压至 tmp/first-release/extracted。
6. 先运行解压目录的 check:content，再合并 data 和 uploads 至本项目 public。保留更新前占位 JSON 于仓库外，未创建 public/public。
7. 当前 public/data/site.json 的版本为 release-13b03682-204b-4c07-bbf0-acd63a151f9b。头像与简历均为 public 引用，指向 /uploads/；没有 local 引用、blob URL、本机路径或待确认文案。
8. 运行 lint、测试及生产构建。在此前未导入任何草稿的新 origin 127.0.0.1:4178 首先访问公开首页，确认内容和静态头像正常，再下载 PDF 并与公开副本比较。
9. 在 375、768、1440px 下检查首页、两项公开详情、/admin/profile，共 12 组。每组核实实际视口宽度与设置一致，无横向溢出。直接打开及刷新管理页和项目详情正常。
