## 使用边界及下一步

localStorage 与 IndexedDB 没有跨存储的原子事务；实现采用先保存新文件、再提交文字引用的顺序，失败时尽量回收新文件并保留原草稿。不同域名、端口、设备、浏览器之间不自动同步；浏览器清理数据可能丢失本机草稿，应定期导出完整备份。

发布 ZIP 是合并至项目 public 的数据和资源包，不是可直接上传 Cloudflare 的完整 dist。合并后重新构建，才得到可部署站点。导出操作本身不修改公开站点。

当前完成 A—E 的本地开发及发布流程验证；尚未创建 GitHub 仓库、推送代码或部署 Cloudflare Pages，也没有正式域名。下一步填写真实资料，预览并导出，按 README 将发布内容合并、构建，再上传 GitHub 并连接 Cloudflare Pages。
