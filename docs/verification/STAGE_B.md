# 阶段 B：内容管理验证记录

日期：2026-10-16。项目目录：`C:\AITraining\personal-sites\personal-portfolio`。

## 实现内容

- 个人信息、教育经历、联系方式表单，字段级校验与保存反馈。
- 技能和项目新增、编辑、删除二次确认、上移/下移立即保存。
- 项目展示开关、技术栈与亮点编辑。
- 技能分类展示；项目卡片链接到独立详情。
- 公开 `/projects/:id` 与草稿 `/preview/projects/:id` 分别读取对应数据源。
- 本机文字保存在 localStorage；公开 site.json 保持原有占位内容，未添加虚构履历。
- 所有存储读写通过 src/api；更新从最新草稿合并，保留其他条目和文件引用。
- 损坏草稿不被自动覆盖，存储失败有错误反馈；过期编辑和删除会被拒绝。

## 边界与后续

本机 localStorage 不提供跨标签页原子事务或多人协作能力；通过读取最新草稿、同页串行写入与过期条目检查减少覆盖。未保存的表单输入不会自动持久化，需点击保存。

尚未接入 IndexedDB、头像/PDF 上传、完整备份导入导出、静态发布包及实际线上部署。公开版目前保持用户提供前的占位内容，没有为了演示而编造履历。详情 UI 使用草稿数据完成正向实测；公开版暂无真实项目，验证了未发布项目不可见和数据源隔离。
